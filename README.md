# -SMART-SECURITY-SYSTEM-
Smart Security System

♂️Overview

This project is a Smart Security System built using an ESP32 and a PIR Motion Sensor. It detects human motion and activates a buzzer and LED to alert the user. The ESP32 can also send notifications over Wi-Fi, making it a simple IoT-based security solution.

⚙️Features

- Motion detection using a PIR sensor
- Buzzer alarm
- LED indication
- ESP32-based control
- Wi-Fi notification support

🪤Components Used

- ESP32 Development Board
- PIR Motion Sensor (HC-SR501)
- Active Buzzer
- LED
- 220Ω Resistor
- Breadboard
- Jumper Wires
- USB Cable

🛠️Working

The PIR sensor continuously monitors for motion. When motion is detected, the ESP32 receives the signal and turns on the buzzer and LED. If Wi-Fi is enabled, the system can also send a notification to the user's phone.

🈸Applications

- Home Security
- Office Security
- Garage Monitoring
- Room Monitoring

🔮Future Improvements

- Add ESP32-CAM for image capture
- Add RFID or keypad for access control
- Add battery backup
- Connect to a cloud dashboard
